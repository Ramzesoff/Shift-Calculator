# Changelog

Все значимые изменения проекта. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [v5.0] - 2026-11-21
### Добавлено
- Графический интерфейс пользователя (GUI) на базе библиотеки `tkinter` (файл `gui.py`)

## [v4.0] - 2026-11-19
### Изменено
- Проведен рефакторинг: код разбит на модули `main.py`, `storage.py` и `logic.py`
- Убраны глобальные переменные для работы с файлами

## [v3.0] - 2026-11-19
### Добавлено
- Удаление смены по номеру
- Статистика по конкретному месяцу и году

## [v2.0] - 2026-11-19
### Добавлено
- Сохранение смен в JSON (`json.dump`)
- Загрузка данных при старте программы (`json.load`)
- Файл `shifts.json` добавлен в `.gitignore` для защиты личных данных

## [v1.0] - 2026-11-15
### Добавлено
- Базовое меню: добавление, просмотр, итог, количество, средняя зарплата
- Хранение смен в списке (в памяти)
- Обработка ошибок ввода (`try/except ValueError`)
